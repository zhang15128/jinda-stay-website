# 仁达连锁民宿酒店网站

这是「仁达」大阪连锁民宿酒店官网项目的当前公开基线版本。项目面向真实业务继续开发，当前网站主要承担品牌展示、住宿物件介绍、入住指南和外部预订引导；价格、库存和正式订单仍由 Booking.com、Agoda、Trip.com 等平台处理。

## 项目目标

- 用日语、英语、繁体中文、简体中文、韩语、越南语和印地语介绍大阪的住宿物件。
- 让客人先确认想入住的物件、地址、地图和入住方式，再进入 OTA 平台查看价格与空房。
- 把入住前信息、入口二维码引导、门锁操作、房内设备和退房时间集中整理在入住指南中。
- 在手机和桌面端都提供清晰、可实际点击的浏览路径。

## 当前功能

- 首页大阪城市图片轮换，支持左右切换、响应式布局和多语言切换。
- 五个住宿物件入口：仁达日本桥、仁达难波南、仁达荣本町、仁达系统院、仁达 hotel。
- 每个物件均可查看地址、Google Maps、周边设施、房内介绍和入住流程；系统院的房型与外部 OTA 入口仍在准备中。
- 独立入住指南页面，包含地图、门锁操作演示、房内媒体区域和周边设施信息。
- 门锁操作使用虚拟示例密码和动画演示，不公开真实门禁密码。
- 联系方式图标入口：LINE、Gmail、WeChat、WhatsApp 和电话。
- 保留房型选择页面作为后续扩展能力，但当前主要预订路径已经调整为「先选物件，再进入 OTA」。

## 本地运行

这是一个不依赖构建工具的静态网站。可以在项目目录执行：

```powershell
python -m http.server 4173
```

然后打开 `http://localhost:4173/`。直接双击 HTML 文件也可以查看部分内容，但使用本地 HTTP 服务更接近实际部署环境。

## 安全边界

- 真实门禁密码、客户资料、账号、API 密钥和内部文件不得提交到 GitHub。
- 含真实门禁信息的原始视频和海报已通过 `.gitignore` 排除。
- 公共演示只使用虚拟示例密码、虚拟动画或已处理的安全素材。
- 本项目当前没有自建订单、支付、用户账户或后台管理系统。

## 当前状态

当前为可继续开发的静态网站基线，不等同于已经接入正式运营系统。下一步可以继续完善各物件的真实房内照片、经过脱敏的入住演示素材、OTA 正式链接、地图信息和 Cloudflare Pages 的自动部署连接。
